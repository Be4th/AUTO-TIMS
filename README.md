Auto Tims
 -- Quick note August 24, 26. This project was from 4 years ago and may not work right now however with a few tweeks this can most likly be functional again.
 
I developed this automation project for Tim Hortons' customer survey, called Auto Tims, while in high school using Python.

I would often go to Tim Horton's and they would ask me the same questions and I'd answer them the same way. Instead of having to fill the survey out every time, I chose the project to be automated as a programming project.

 Overview

Auto Tims automates the survey completion process using Python and Selenium with the help of a survey code. The application processes the survey and produces the validation code which can then be used to get the provide survey offer.

The project includes:

 A Python-based Automation System to interface with Selenium.Python Automation System using Selenium.
 It is an interface supported with GUI to make interactions more user friendly.
 Automated survey completion
 Automatic retrieval of validation code and displaying the same.
 An independent program which can be played with friends

 How It Works

Install necessary Python packages, including selenium.
2. Type the survey code given by Tim Hortons.
3. Auto Tims starts the investigation and fills in the necessary questions.
The validation code is shown, which is required for the relevant survey offer.

 Development

This script for the automation of a small part of the program evolved into a full-fledged desktop application with a GUI. Ideally I wanted to create a custom logo to put on the project so I did that in Photoshop.

This project was one of the first to be a complete application where I was able to use Python programming, browser automation, GUI development and software packaging.
